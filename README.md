# Projeto PO: Otimização da Tomada de Decisão de Goleiros em Pênaltis

Repositório de dados e modelagem do **Grupo 11** (Pesquisa Operacional Aplicada, UFABC Q3/2026), combinando Programação Linear e Teoria dos Jogos (jogos de soma zero, estratégias mistas e Equilíbrio de Nash).

## Estrutura
- `data/raw/`: bases brutas extraídas (`penalties_dataset_sofascore.csv`, 16.629 cobranças).
- `data/processed/`: bases limpas e matrizes de payoff calibradas (etapas M1 e M2).

## Fonte de Dados
- **16k+ Football Penalties Dataset (GK vs Shooter)**: `https://www.kaggle.com/datasets/saadmbt/16k-football-penalties-dataset-gk-vs-shooter` (`penalties_dataset_sofascore.csv`, 16.629 linhas, 27 colunas).
